# Recuperação do Orça Fácil Pro

O repositório contém o protótipo web e o código Android documentado no README. Os instaladores de teste 1.30.1 de Windows e Android foram recuperados de uma cópia local. O código-fonte desta versão ainda precisa ser localizado e conferido com os binários.

No Windows, o instalador 1.30.1 abre o OrcaFacil PC - TESTE. O painel inicial oferece **Abrir sincronização**. Use a mesma conta do aplicativo nos dois aparelhos.
